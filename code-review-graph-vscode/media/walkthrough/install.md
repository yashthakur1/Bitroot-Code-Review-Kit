## Install the Backend

Bitroot Code Review needs a Python backend to parse your codebase.

**Requirements:** Python 3.10+

**Recommended:** Install via [uv](https://docs.astral.sh/uv/):
```bash
uv pip install Bitroot Code Review
```

**Alternatives:**
```bash
pipx install Bitroot Code Review
# or
pip install Bitroot Code Review
```
